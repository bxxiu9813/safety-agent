病安通報 Q&A 速查系統

依醫策會 TPR 13 大官方事件類別與常見疑義整理

醫療品質部 病人安全科 製 ｜ 更新日期：2026/08/13
依醫策會 13 大通報類別篩選：
檢查/檢驗/病理切片事件
病人手術，術中切下組織標本送驗，但後來發現送出的標本無法確定是否為當初指定送檢的檢體，請問嚴重度該如何判斷？
若造成重新採檢之事件，對病人健康的影響程度至少為『輕度』；若此檢體無法再取得(病人組織切片)、取得不易(腦脊髓液)或是再採之檢體(飯前血糖)品質無法等同前一次之檢體遺失，則依據是否對病情延遲診斷或後續處置的影響程度判定嚴重度。
檢查/檢驗/病理切片事件
單位欲傳送檢體，下單系統時下錯任務別，導致檢體延遲送檢，該歸類為「其他事件」還是「檢查/檢驗/病理切片」事件？
請通報「檢查檢驗病理切片事件」，發生階段(可複選)->採檢/送檢階段->勾選「檢體延遲送檢」及其他：說明下單系統時人為因素下錯任務別。
跌倒事件
病人原坐在椅子上，慢慢暈倒滑落地上，此事件需要通報TPR嗎？如果需要應歸類於什麼事件？
請通報「跌倒事件」，並依實際造成病人跌倒的原因勾選。
檢查/檢驗/病理切片事件
同一病人檢病理切片檢體兩件，兩檢體罐標籤互換貼錯 => 該歸類為檢查檢驗病理切片事件還是手術事件？
通報至「檢查檢驗病理切片事件」→ 勾選「事件發生階段」→「採檢/送檢階段」→「標籤錯誤」，並依實際狀況評估填寫。
檢查/檢驗/病理切片事件
手術中檢體遺失該歸類為手術事件還是檢查檢驗病理切片事件？若屬於手術事件，檢體該如何判斷應歸類為手術事件還是檢驗檢查病理切片事件？
依據台灣病安通報系統 Q&A -> 檢查檢驗 NO.L001，此事件請通報為「檢查/檢驗/病理切片事件」，事件發生階段請勾選『採檢/送檢階段/檢體遺失或損毀』。建議機構也在手術流程中改善，例如術前即在手術室備好檢體留存之器具。
藥物事件
病人使用抗生素治療，手術當日主護早上的抗生素沒給，未交給麻醉科給藥或詢問主治醫師是否要給藥或停藥，病人於未打抗生素狀況進行長時間手術。請問此事件該歸類為藥物事件或醫療照護事件？
請通報至「藥物事件」/遺漏給藥。
不需通報 / 非TPR範疇
醫療處置紀錄單遭同仁冒用姓名是否該通報？如須通報應通報何種異常事件？
根據描述，建議內部溝通改善即可，不需通報至TPR。
跌倒事件 / 通報判定原則
通報事件中此類事件再次發生的頻率是以事件類別（如：跌倒事件發生的頻率）做判斷，還是以事件類型（如：因"踩到拖鞋"跌倒的頻率）做判斷？
此類事件再次發生的可能情形（意指本次事件"依情境與經驗"評估可能再發生的機會）；例如通報跌倒事件：病人因服藥後產生暈眩下床上廁所發生跌倒，類似此情況再次發生的機會？會因過往經驗發生的頻率為參考。
跌倒事件
若"病人家屬"在浴室入口處滑倒，至急診求診後，發現左側肋骨斷掉一根（未開刀），傷害程度應如何判定？
此事件發生對象為家屬，無法評估傷害程度。相關 QA 請檢視病人安全資訊網 Q&A 編號：F010。
檢查/檢驗/病理切片事件
病人拿著檢查單要來照 KUB X-Ray，詢問病人的姓名，發現病人手上拿的檢查單是 B 這個病人的檢查單，致電診間後確認給錯檢查單張，請問此事件該歸類至何種事件類別？
請通報至「檢查/檢驗/病理切片事件」 -> 檢查(驗)單交付錯誤。
跌倒事件 / 公共意外事件
病人欲至門診看診，機車停在私人機車場，走至門診機車入口之慢車道時跌倒，請問此範圍是否歸屬於院內區域，是否需進行通報？
需先釐清「病人跌倒之慢車道，是否屬醫院院區範圍或由醫院負責管理維護？」若跌倒事件發生於醫院可管理、可改善之環境，則屬 TPR 通報範圍。
不需通報 / 非TPR範疇
病人需緊急使用後線抗癲癇藥物，因院內未常備該藥品需辦理急採，可能造成治療延遲。此類事件是否屬於病人安全事件收案範疇？
本案因非常備藥品且需辦理緊急採購後始能取得，屬藥品配置及供應機制管理，未涉及醫療照護過程中之異常事件，因此不屬 TPR 病人安全事件收案範疇。
醫療照護事件
病人左肩脫臼復位後以三角巾固定，做右肩 CT 檢查時依指示雙上肢舉高，隨後左肩再次脫臼。請問此事件該歸類為何種事件類別？
建議通報為「醫療照護事件」，發生階段勾選「評估」->「未評估」及「處置、治療或照護」->「處置問題」，並依病人實際受傷害情形填報健康影響程度。
藥物事件
給予 Propofol 鎮靜時發現 IV 注射部位腫脹外漏，現場立即停止並處理。請問此案件應歸類為何種類別？
請通報至「藥物事件」。
不需通報 / 非TPR範疇
病房協助病人掛號牙科門診，但牙科現場表示不接受該掛號方式需重新抽牌，系統與現場作業不一致導致病人無法如期就診。請問是否需通報？
院內掛號系統設定與牙科門診作業流程不一致，屬行政流程及系統管理問題，不須通報至 TPR。
手術事件
手術室尚未準備完成就被通知病人已被醫師帶至術前，沒有經過刀房控台通知也沒有經交班，不符合標準流程。應歸類醫療照護還是手術事件？
建議通報至「手術事件」 / 發生階段：術前準備 / 類型：術前準備程序不完善。
不需通報 / 非TPR範疇
病人至院外散步，因人行道高低差踩空擦傷。請問此事件是否須通報至 TPR？
病人在非醫療照護環境中發生的跌倒情況，因院外環境無法改善，不須通報 TPR。
醫療照護事件 / 其他事件
因排班資訊誤植，致使重大外傷機制時無法即時聯繫到值班醫師，請問此事件該歸類為其他事件或是醫療照護事件？
1. 若僅為單純排班資訊誤植，未影響到病人照護流程，屬行政/資訊面管理問題，建議機構內部檢討改善即可。
2. 若因此造成延誤急救、治療或緊急處置流程等情形，進而增加病人風險或已影響到病人照護，請通報至「醫療照護事件」。
公共意外事件
氧氣流量表掉下來打到病人的額頭，產生破皮傷口，請問此事件應歸類至何種事件？
此事件為設備物品固定不良與環境安全異常有關，建議通報至「公共意外事件」。
手術事件 / 跌倒事件
手術中約束帶疑似承受過大壓力彈開，導致病人自床上滑落。應歸類為手術事件或跌倒事件？
若一項事件跨兩個範疇時，請以對病人健康影響程度較嚴重者進行通報。
公共意外事件 / 藥物事件
病人接上化療藥後，化療藥物由 Bag 的加藥處滲漏出來。請問此事件該歸類為何種事件分類？
化療藥物滲漏若潑灑於地面，請通報至「公共意外事件」；若侷限於皮膚組織內，請通報至「藥物事件」。並請釐清是否有醫材不良的問題。
手術事件 / 其他事件
主護發現麻醉同意書已被簽署且簽署人非病人家屬。請問此事件該歸種事件？
若因同意書未填或填寫不完整導致手術中斷或延誤，造成治療或處置問題時，請通報至「手術事件」。若未牽涉治療處置（如不及時補簽未影響排程），建議通報至「其他事件」。
檢查/檢驗/病理切片事件
心電圖覆核報告註記高風險診斷，但未即時通知臨床團隊或已出院之病人。此案件該歸類於事件發生的哪個階段？
請通報至「檢查/檢驗/病理切片事件」→ 檢查單位報告階段 → 報告延遲。
手術事件
病人本次住院不需進行手術，但因門診舊有同意書存在，護理師無醫囑下被通知並將病人推至開刀房。應歸類為醫療照護還是手術事件？
請通報至「手術事件」 → 術前準備 → 術前準備程序不完善，並請依發生實際狀況進行填報。
治安事件 (不需通報 / 非TPR範疇)
病人家屬在等候區被陌生男子以幫忙買特效藥膏為由詐騙，請問是否須通報至 TPR？
詐騙家屬案件不符合病人安全異常事件的定義，不在 TPR 通報範疇內。
公共意外事件
超商微波爐主機板故障導致冒煙觸動偵煙器，是否須通報？對病人影響程度該如何選擇？
若發生地點為照護病人之場域如配膳室、病房裡，且影響到病人造成傷害，請通報「公共意外事件」。
公共意外事件
病人於腹部 X 光檢查結束時，X 光機內定位燈泡破裂，碎屑掉落至病人身上及手上致輕微紅腫，應歸類為公共意外還是醫療照護事件？
建議通報至「公共意外事件」。
跌倒事件 / 傷害行為事件
門診病人於藥局前趴倒在地、大吼大叫並用頭撞地板自殘，後續送急診，應歸類為何種事件？
可通報至「跌倒事件」或「傷害行為事件」，請依實際影響情形判定傷害程度，並以傷害程度較高者之事件類別進行通報即可。
公共意外事件
病人家屬因病室房門故障遭反鎖受困，經相關人員到場處理並破壞門鎖後始順利脫困，請問此事件應歸類通報為何種事件類別？
因病室房門門鎖故障造成家屬受困，請通報至「公共意外」事件；類型->「其他，請說明」
