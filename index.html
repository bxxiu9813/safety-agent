依醫策會 TPR 13 大官方事件類別與常見疑義整理

依醫策會 13 大通報類別篩選：
檢查/檢驗/病理切片事件
病人手術，術中切下組織標本送驗，但後來發現送出的標本無法確定是否為當初指定送檢的檢體，請問嚴重度該如何判斷？
若造成重新採檢之事件，對病人健康的影響程度至少為『輕度』；若此檢體無法再取得(病人組織切片)、取得不易(腦脊髓液)或是再採之檢體(飯前血糖)品質無法等同前一次之檢體遺失，則依據是否對病情延遲診斷或後續處置的影響程度判定嚴重度。
檢查/檢驗/病理切片事件
單位欲傳送檢體，下單系統時下錯任務別，導致檢體延遲送檢，該歸類為「其他事件」還是「檢查/檢驗/病理切片」事件？
請通報「檢查檢驗病理切片事件」，發生階段(可複選)->採檢/送檢階段->勾選「檢體延遲送檢」及其他：說明下單系統時人為因素下錯任務別。
跌倒事件
病人原坐在椅子上，慢慢暈倒滑落地上，此事件需要通報TPR嗎？如果需要應歸類於什麼事件？
請通報「跌倒事件」，並依實際造成病人跌倒的原因勾選。
檢查/檢驗/病理切片事件
同一病人檢病理切片檢體兩件，兩檢體罐標籤互換貼錯 => 該歸類為檢查檢驗病理切片事件還是手術事件？
通報至「檢查檢驗病理切片事件」→ 勾選「事件發生階段」→「採檢/送檢階段」→「標籤錯誤」，並依實際狀況評估填寫。
檢查/檢驗/病理切片事件
手術中檢體遺失該歸類為手術事件還是檢查檢驗病理切片事件？若屬於手術事件，檢體該如何判斷應歸類為手術事件還是檢驗檢查病理切片事件？
依據台灣病安通報系統 Q&A -> 檢查檢驗 NO.L001，此事件請通報為「檢查/檢驗/病理切片事件」，事件發生階段請勾選『採檢/送檢階段/檢體遺失或損毀』。建議機構也在手術流程中改善，例如術前即在手術室備好檢體留存之器具。
藥物事件
病人使用抗生素治療，手術當日主護早上的抗生素沒給，未交給麻醉科給藥或詢問主治醫師是否要給藥或停藥，病人於未打抗生素狀況進行長時間手術。請問此事件該歸類為藥物事件或醫療照護事件？
請通報至「藥物事件」/遺漏給藥。
不需通報 / 非TPR範疇
醫療處置紀錄單遭同仁冒用姓名是否該通報？如須通報應通報何種異常事件？
根據描述，建議內部溝通改善即可，不需通報至TPR。
跌倒事件 / 通報判定原則
通報事件中此類事件再次發生的頻率是以事件類別（如：跌倒事件發生的頻率）做判斷，還是以事件類型（如：因"踩到拖鞋"跌倒的頻率）做判斷？
此類事件再次發生的可能情形（意指本次事件"依情境與經驗"評估可能再發生的機會）；例如通報跌倒事件：病人因服藥後產生暈眩下床上廁所發生跌倒，類似此情況再次發生的機會？會因過往經驗發生的頻率為參考。
跌倒事件
若"病人家屬"在浴室入口處滑倒，至急診求診後，發現左側肋骨斷掉一根（未開刀），傷害程度應如何判定？
此事件發生對象為家屬，無法評估傷害程度。相關 QA 請檢視病人安全資訊網 Q&A 編號：F010。
檢查/檢驗/病理切片事件
病人拿著檢查單要來照 KUB X-Ray，詢問病人的姓名，發現病人手上拿的檢查單是 B 這個病人的檢查單，致電診間後確認給錯檢查單張，請問此事件該歸類至何種事件類別？
請通報至「檢查/檢驗/病理切片事件」 -> 檢查(驗)單交付錯誤。
跌倒事件 / 公共意外事件
病人欲至門診看診，機車停在私人機車場，走至門診機車入口之慢車道時跌倒，請問此範圍是否歸屬於院內區域，是否需進行通報？
需先釐清「病人跌倒之慢車道，是否屬醫院院區範圍或由醫院負責管理維護？」若跌倒事件發生於醫院可管理、可改善之環境，則屬 TPR 通報範圍。
不需通報 / 非TPR範疇
病人需緊急使用後線抗癲癇藥物，因院內未常備該藥品需辦理急採，可能造成治療延遲。此類事件是否屬於病人安全事件收案範疇？
本案因非常備藥品且需辦理緊急採購後始能取得，屬藥品配置及供應機制管理，未涉及醫療照護過程中之異常事件，因此不屬 TPR 病人安全事件收案範疇。
醫療照護事件
病人左肩脫臼復位後以三角巾固定，做右肩 CT 檢查時依指示雙上肢舉高，隨後左肩再次脫臼。請問此事件該歸類為何種事件類別？
建議通報為「醫療照護事件」，發生階段勾選「評估」->「未評估」及「處置、治療或照護」->「處置問題」，並依病人實際受傷害情形填報健康影響程度。
藥物事件
給予 Propofol 鎮靜時發現 IV 注射部位腫脹外漏，現場立即停止並處理。請問此案件應歸類為何種類別？
請通報至「藥物事件」。
不需通報 / 非TPR範疇
病房協助病人掛號牙科門診，但牙科現場表示不接受該掛號方式需重新抽牌，系統與現場作業不一致導致病人無法如期就診。請問是否需通報？
院內掛號系統設定與牙科門診作業流程不一致，屬行政流程及系統管理問題，不須通報至 TPR。
手術事件
手術室尚未準備完成就被通知病人已被醫師帶至術前，沒有經過刀房控台通知也沒有經交班，不符合標準流程。應歸類醫療照護還是手術事件？
建議通報至「手術事件」 / 發生階段：術前準備 / 類型：術前準備程序不完善。
不需通報 / 非TPR範疇
病人至院外散步，因人行道高低差踩空擦傷。請問此事件是否須通報至 TPR？
病人在非醫療照護環境中發生的跌倒情況，因院外環境無法改善，不須通報 TPR。
醫療照護事件 / 其他事件
因排班資訊誤植，致使重大外傷機制時無法即時聯繫到值班醫師，請問此事件該歸類為其他事件或是醫療照護事件？
1. 若僅為單純排班資訊誤植，未影響到病人照護流程，屬行政/資訊面管理問題，建議機構內部檢討改善即可。
2. 若因此造成延誤急救、治療或緊急處置流程等情形，進而增加病人風險或已影響到病人照護，請通報至「醫療照護事件」。
公共意外事件
氧氣流量表掉下來打到病人的額頭，產生破皮傷口，請問此事件應歸類至何種事件？
此事件為設備物品固定不良與環境安全異常有關，建議通報至「公共意外事件」。
手術事件 / 跌倒事件
手術中約束帶疑似承受過大壓力彈開，導致病人自床上滑落。應歸類為手術事件或跌倒事件？
若一項事件跨兩個範疇時，請以對病人健康影響程度較嚴重者進行通報。
公共意外事件 / 藥物事件
病人接上化療藥後，化療藥物由 Bag 的加藥處滲漏出來。請問此事件該歸類為何種事件分類？
化療藥物滲漏若潑灑於地面，請通報至「公共意外事件」；若侷限於皮膚組織內，請通報至「藥物事件」。並請釐清是否有醫材不良的問題。
手術事件 / 其他事件
主護發現麻醉同意書已被簽署且簽署人非病人家屬。請問此事件該歸種事件？
若因同意書未填或填寫不完整導致手術中斷或延誤，造成治療或處置問題時，請通報至「手術事件」。若未牽涉治療處置（如不及時補簽未影響排程），建議通報至「其他事件」。
檢查/檢驗/病理切片事件
心電圖覆核報告註記高風險診斷，但未即時通知臨床團隊或已出院之病人。此案件該歸類於事件發生的哪個階段？
請通報至「檢查/檢驗/病理切片事件」→ 檢查單位報告階段 → 報告延遲。
手術事件
病人本次住院不需進行手術，但因門診舊有同意書存在，護理師無醫囑下被通知並將病人推至開刀房。應歸類為醫療照護還是手術事件？
請通報至「手術事件」 → 術前準備 → 術前準備程序不完善，並請依發生實際狀況進行填報。
治安事件 (不需通報 / 非TPR範疇)
病人家屬在等候區被陌生男子以幫忙買特效藥膏為由詐騙，請問是否須通報至 TPR？
詐騙家屬案件不符合病人安全異常事件的定義，不在 TPR 通報範疇內。
公共意外事件
超商微波爐主機板故障導致冒煙觸動偵煙器，是否須通報？對病人影響程度該如何選擇？
若發生地點為照護病人之場域如配膳室、病房裡，且影響到病人造成傷害，請通報「公共意外事件」。
公共意外事件
病人於腹部 X 光檢查結束時，X 光機內定位燈泡破裂，碎屑掉落至病人身上及手上致輕微紅腫，應歸類為公共意外還是醫療照護事件？
建議通報至「公共意外事件」。
跌倒事件 / 傷害行為事件
門診病人於藥局前趴倒在地、大吼大叫並用頭撞地板自殘，後續送急診，應歸類為何種事件？
可通報至「跌倒事件」或「傷害行為事件」，請依實際影響情形判定傷害程度，並以傷害程度較高者之事件類別進行通報即可。
公共意外事件
病人家屬因病室房門故障遭反鎖受困，經相關人員到場處理並破壞門鎖後始順利脫困，請問此事件應歸類通報為何種事件類別？
因病室房門門鎖故障造成家屬受困，請通報至「公共意外事件」；類型->「其他，請說明」
公共意外事件 / 不需通報 / 非TPR範疇
醫療作業系統當機，造成許多部門因而發生異常事件，如藥局給藥劑量錯誤、檢驗科檢驗延遲等，應通報和類事件?嚴重度如何判定？
1.電腦系統性當機請通報公共意外。實際造成事件發生之單位，應對病人傷害的嚴重度進行後續追蹤，再依病人所受的傷害做為嚴重程度之判定。 2.單位、行動護理車、診間之電腦或印表機等設備，血液透析、呼吸器、檢查檢驗單位的儀器設備於病人使用中當機，導致病人處置或照護因而中斷或延遲，可依通報內容通報藥物或醫療照護或檢驗檢查事件。 3.若單位、診間電腦或檢查檢驗單位的儀器設備開機後當機或異常，尚未開始與病人相關處置或照護，不須通報TPR。
公共意外事件
1.A病人站在逃生門後方，B病人從另一方推門，導致A病人被門撞傷。2.家屬使用床欄時不慎夾到食指，血流不止，醫護人員立即給予包紮，協助家屬至急診縫合。
凡機構內設計動線不良、或因所提供設施、器材未定期檢修而故障、掉落造成人員傷害，請通報公共意外，類型勾選「其他」並加以說明。
公共意外事件 / 藥物事件
1.公共意外中有毒物質包含哪些?影響範圍多大才算公共意外?2.病房的體溫計掉落地上破裂，導致水銀外露，化療藥物因接頭鬆脫外漏，直接滴注於床單/地板。3.滴注化療藥物滲漏於皮膚組織內，只須通報藥物事件嗎?4.若病人同時發生化療藥物滲漏於組織與潑灑地面該如何通報?
1.TPR收受之公共意外事件目前有化學物質外洩及輻射物質外洩，未限制有毒物質種類及影響範圍，只要有影響病人之虞，皆歡迎通報。2.水銀、化療藥物均為具毒性化學物質，應通報為公共意外事件之化學物質外洩。3. 滴注化療藥物滲漏侷限於皮膚組織內，請通報藥物事件→給藥階段錯誤→藥物滲漏。4.以對病人傷害嚴重度較高之事件為主要通報事件。若組織滲漏傷害較為嚴重則通報藥物事件，反之亦然。
公共意外事件
1.高壓鍋突然沒蒸氣，通報工務組已經過1小時還是沒有蒸氣。2.修理水塔未公告，供應中心消毒後，高壓消毒鍋門無法打開，打電話至工務室才得知水塔正在維修，鍋內有開刀房器械無法取出；其他鍋也無法消毒，導致門診與其他單位無法換消。
因高壓消毒鍋能否正常使用將會影響後續無菌器械的正常供應，若因此影響器械、物品之滅菌狀況或延誤病人療程，則可通報公共意外事件→其他，請說明：高壓消毒鍋異常。
公共意外事件
公共意外事件定義?
凡醫療機構有管理及使用範圍之場所，例如:醫療機構之建築物、通道、機器、電梯、停車場(含委外經營)、其他工作物…等造成病人傷害皆屬之，受影響對象往往很廣泛，有時可能不只侷限一人。
院內不預期心跳停止事件
院內不預期心跳停止事件定義?
院內不預期心跳停止(UNEXPECTED CARDIAC ARREST) 事件定義為病人非因原疾病病程可預期而需要急救的情況，所稱「心跳停止」或「心肺停止」指臨床上廣義之無脈搏及無呼吸之情形。
院內不預期心跳停止事件
病人心跳停止後須急救，是否才要通報?病人因發生VF而需要急救，是否要通報?
建議先檢視事件並分類為預期性或非預期性，再將非預期性心跳停止(Unexpected cardiac arrest) 且急救過程中曾經發生心跳停止事件上傳至TPR系統。
院內不預期心跳停止事件
病人因肺炎入院，24小時內，急救時發現X光相較於剛入院時呈現快速惡化(惡化速度超過預期，急救前尚未發出病危通知書)，是否符合院內不預期心跳停止定義?
如果病人因肺炎入院，不到24小時內，急救時發現X光相較於剛入院時呈現快速惡化(惡化速度超過預期，急救前尚未發出病危通知書)。此狀況已超乎原疾病病程進展預期而予以急救，故請通報至TPR系統。
院內不預期心跳停止事件
病人病程中可預期心跳停止，但未簽屬DNR，要通報何種事件?
是否簽署DNR可作為協助判定此次心跳停止是否為「不預期」的參考之一，事件是否屬「院內不預期心跳停止」仍應由通報機構醫療照護人員(尤其是醫師)之專業判定，部分機構係透過召開急救案例討論會、死亡案例討論會等確認之。若病人心跳停止為其病程「可預期」之情形，不論有無完成簽署DNR，均不需通報至TPR。
院內不預期心跳停止事件
「不預期心跳停止」之填表內容中，「急救最終出院狀況」部分，若有救回由一般病房轉加護病房，如何選擇?或者需要等該病人離院後再補填?
本欄位選項是呈現「出院狀況」，若急救後由一般病房轉加護病房，此項目是無法填寫的；建議追蹤至出院，再依實際狀況勾選。
治安事件
恐嚇屬於哪一類事件?
恐嚇與治安相關，需要通報警政單位，屬於治安事件。
治安事件
疑似發現毒品針頭，該歸類至哪一類事件?
請通報「治安事件」，類型勾選『使用違禁品』。
治安事件
病人的錢或個人物品被偷了，雖然沒有造成身體傷害，但是造成病人心理上創傷，嚴重度該如何判定?
TPR目前嚴重度判定以病人生理傷害為原則，若無造成生理傷害則請勾選無傷害。
治安事件
精神科病人私藏筷子、電池及燈泡等，請問應通報治安事件還是傷害行為事件?
筷子、電池及燈泡為精神科病房之違禁品，請通報「治安事件」，類型勾選『使用違禁品』。
治安事件
精神科病人不假外出或失蹤，後續有可能在院內或院外其他地方追蹤到病人下落，要通報治安事件或醫療照護事件?嚴重度如何判定?
1.精神科住院病人應在限制的環境中活動，即使病人未離開醫院，但因已私自離開所限制的範圍，仍應通報治安事件中的病人失蹤(含私自離院)，即使後來聯絡上病人或是病人被家屬送回醫院繼續就醫，仍須通報TPR系統。若是心智障礙病人失蹤，則可視為警訊事件sentinel event；並依實際影響判定傷害程度。 2.病人逾假未歸但有連絡上病人，醫師同意延後請假時間，不需要通報TPR；但是逾假未歸且聯絡不上病人或家屬，須通報TPR。

單位財產遺失，如:器械遺失，也是通報治安事件嗎?
單位財產遺失，亦請先釐清問題的原因。若是蓄意偷竊行為，方屬於「治安事件」。
治安事件
若住院病人告知家屬要吃早餐，從病房離開後自行回到家中自殺，是否須通報TPR?該事件是否需進行RCA?
1. 若病人沒有完成請假程序，建議通報「治安事件」→「病人失蹤（含私自離院）」，並依據其嚴重度勾選對病人健康造成的影響。 2.貴機構可依本事件『可能再次發生頻率』及『傷害嚴重程度』算出SAC級數 (SAC級數可參考台灣病人安全系統網頁/統計報表/年報表/2011年報表169頁)，建議SAC達1或2的事件或警訊事件應進行RCA分析。
治安事件
病人由家屬陪入急診待床中，凌晨發現病人不在床位，且留置針及手圈遺留在地上；電聯告知病人目前仍於急診待床治療中，建議立即返，早上七點病人由家屬、警察及119送入急診，病人情緒激動，予針劑治療及口服藥物使用，請問急診病人不假外出多久算私自離院?是否須通報至治安事件?
TPR沒有明訂要離院多少小時，才能通報私自離院，原則上病人失蹤（含私自離院）只要有病人安全上的顧慮 ，都建議通報。
治安事件
查房時有看到病人，後續病人不假外出，急診打電話至單位告知病人跌倒被救護車送至急診，警衛協助坐輪椅回病房，病人沉默不語，詢問病人如何跌倒，主訴走路跌倒，請問此案件應通報治安事件或跌倒事件?或兩者皆須通報?
1.若病人沒有完成請假程序，建議通報「治安事件」，類型勾選『病人失蹤（含私自離院）』；並依實際影響判定傷害程度。 2.病人於院外跌倒不用通報至TPR。
治安事件 / 醫療照護事件
醫療處置過程，醫師突然對病人大吼大叫，應通報何種異常事件?
醫療人員對病人有言語上或肢體上的衝突，請通報「治安事件」，類型勾選『肢體或言語衝突』；若此事件因此延誤醫療處置，則通報「醫療照護事件」。
其他事件
病人的病歷遺失，是否須通報?應通報為何種事件??
若病歷遺失但未延遲治療及處置，由非醫療照護行為導致，且無法得知具體影響程度，應歸於「其他事件」並加以陳述。若病歷遺失造成病人治療及處置問題，則依實際發生情形通報事件類別及嚴重度。
其他事件
病人打翻杯子，被熱水燙到，是否須通報至TPR系統?若須通報應通報至何種事件?
此事件需通報，請通報為其他事件。
其他事件
病人本身有活動式假牙，家屬餵食時主訴假牙脫落，但並不確定原有假牙為上排或下排，故先安排KUB攝影，發現假牙在病人的十二指腸中，後續安排胃鏡取出。請問該事件非醫療照護事件中所產生，須通報至TPR嗎?如須通報應歸屬何種事件?
本案確實已造成病人非原有疾病所需要額外醫療處置(胃鏡夾出)，故屬病人安全事件，請通報至TPR其他事件，並建議了解事件發生可能原因，如是否因為評估不完整、衛教或溝通等問題，以利進行改善措施，避免同樣不良事件再發生。
其他事件
若病人冒用身分，護理人員病人就診時發現且及時阻止，是否須通報至TPR?
病人持他人健保卡就醫，如未及時辨識，將影響病歷記載、檢查報告之正確性，可能造成病人安全事件，此類事件應通報為「其他事件」，如果在醫療處置前及時發現可判定為跡近錯失。
其他事件
病人送檢，檢查室人員發現病人未帶手圈，應通報至何種事件?
請通報「其他事件」。
麻醉事件
若是在麻醉過程中發生不預期心跳停止事件，應通報「院內不預期心跳停止事件」或「麻醉事件」?
「麻醉事件」蒐集的資料範圍為「與麻醉過程相關之異常事件」，如您所述，事件發生於「麻醉過程中」，故請通報「麻醉事件」，事件發生類型可勾選「麻醉期間心跳停止」。
跌倒事件
病人跌倒後造成傷害(如擦傷紅腫、撕裂傷)，本應額外探視另做處理，如傷口包紮等，但病人拒絕治療，事件發生後對病人的影響程度應如何判定?
病人之傷害嚴重度應依其實際所受傷害程度判定，因此病人是否拒絕治療並不影響其判定。如病人跌倒導致擦傷並貼上OK繃此為輕度傷害；若傷口需縫合、包紮則為中度傷害；造成顱內出血而轉至加護病房照護或因此延長住院天數即為重度傷害；但顱內出血經開刀後成植物人則應判為極重度傷害。
跌倒事件
住院病人主訴大腿疼痛，外觀紅腫，一雌探視後轉急診，於急診照X-RAY發現femoral ftacture，嚴重度該如何判斷?
1. 病人傷害嚴重度依其實際所受傷害程度判定，如病人跌倒導致傷口需縫合、包紮則為中度傷害；造成骨折延長住院天數或顱內出血轉至加護病房照護即為重度傷害；但顱內出血經開刀後成植物人則應判為極重度傷害。 2. 若評估後需轉至其他醫療機構急診後續處理時，應勾選傷害程度中度或中度以上。
跌倒事件
1.醫院大廳辦理活動，因活動需要使用延長線收納館將延長線收納，導致病人踢到收納管跌倒2.病人不停翻動，不甚由手術台/檢查台摔落地面，應通報何種事件?
請通報「跌倒事件」，並依實際造成病人跌倒的原因勾選。
跌倒事件 / 傷害行為事件
病人在房門口前跌倒，協助扶起後病人開始謾罵護理人員及動手攻擊，後續檢視病人傷口，雙腳膝蓋瘀青；請問此事件應通報傷害行為事件或跌倒事件?
請擇嚴重度高之事件通報，如此例跌倒造成的傷害較傷害事件為高，故選擇通報『跌倒事件』。
跌倒事件 / 管路事件
病人在房門口前跌倒，協助扶起後病人開始謾罵護理人員及動手攻擊，後續檢視病人傷口，雙腳膝蓋瘀青；請問此事件應通報傷害行為事件或跌倒事件?
請擇嚴重度高之事件通報，若拔管所造成的傷害較跌倒事件為高則選擇通報『管路事件』，反之亦然。
跌倒事件
1.病人自行如廁因重心不穩滑倒撞到頭，監測生命徵象、照skull X-RAY未發現骨折。2.病人診斷L't tibia Fr，手術後又跌倒；評估病人傷口不會痛，但讓病人照X光後發現有骨折情形，請問對健康的影響程度該如何勾選?
1.只要病人跌倒後經醫師探視評估需額外接受X-ray檢查，對病人健康影響程度請選填中度傷害。 2.由於部分跌倒所致傷害具進展性，請機構以最後確定的嚴重程度通報TPR(例如：病人在事件發生當時只有表皮泛紅、擦傷，但之後的X-ray檢查發現骨折情形需再次開刀延長住院時間，則傷害程度為重度)。
跌倒事件
家屬在院內跌倒是否需進行通報?
跌倒事件的TPR通報目前以收集病人/住民的跌倒事件為主，員工、家屬、訪客，在醫療照護環境中跌倒，由事件發生經過與原因分析所得到的學習改善也可套用於預防病人跌倒與降低傷害上，所以目前TPR針對機構通報的非病人跌倒事件，只要資訊完整便會收案。非病人的跌倒，在事件內容會有些選項比較不好填，例如最近一年跌倒次數、是否為高危險群等，會多為不知道或未評估，請盡量收集跌倒發生時的活動過程、可能原因及事件描述的資訊，以進行統計分析。而在分析事件的嚴重度時，非病人的事件便不會列入。
跌倒事件
1.跌倒事件可能發生原因之「與人員個人因素相關」指的是家屬、醫療人員、病人?若包括病人，與病人生理及行為因素相關，如何區分?2.若是病人因要做椅子，以為已經對準椅子，但因為對準沒坐到椅子導致跌倒，事件原因該如何歸類?
1.與「人員個人因素相關」指的是執行該項作業的相關人員，因此醫院員工、自聘的看護、外包照服員甚至是部分公立機構協助作業的替代役…等均涵蓋其中。 2.建議探究「病人以為」已經對準椅子的原因，例如認知障礙，本體感覺問題，視覺，眩暈…等，或是有設備或環境問題，例如椅子沒固定，椅子太高，地面不平，無支撐物，椅子不夠穩沒有坐到中間便失去平衡而傾倒…等，了解可能原因後選擇合適因素填寫。
跌倒事件
1.病人走路不慎撞到牆壁，造成血腫也算跌倒嗎?2.病人由家屬協助於浴廁洗澡，要出廁所時差點跌倒，因家屬立即扶持故未跌坐至地面，但小指頭撞到牆壁而瘀青，是否須通報至跌倒事件?若須通報，嚴重度是跡近錯失或輕度傷害?
病人因為意外跌落至地面或使身體部位撞擊其他平面(如牆面或傢俱)都屬於跌倒事件通報範圍。
跌倒事件
護理人員正在第1床執行治療，但第2床病人跌倒，是否符合事件發生時有陪伴者之定義?
「事件發生時有無陪伴者」是指事件發生時，病人是否有相關人員(家屬、看護、工作人員)陪伴在側；若護理人員在第一床治療，第二床的病人跌倒，不符合陪伴的定義。
跌倒事件 / 治安事件
病人一直爬起來上廁所，還有偷抽菸行為，對面床看護看到病人拉哲活動是點滴架，不慎拉扯到點滴導致地面潮濕，病人穿著拖鞋不慎滑倒；護理人員發現病人雙膝跪地後往右倒地，立即將病人服制病床上休息，評估未有破皮或寫種情形，病人意識請醒有酒味，主訴未撞擊到頭部，但呼吸費力。請問此事件應通報至跌倒或治安事件，或是兩者皆須通報?
請擇嚴重度高之事件通報，如此例跌倒造成傷害較治安事件為高，故選擇通報『跌倒事件』/與病人生理及行為因素相關/病人飲酒。
手術事件
1.病人於開刀房麻醉以後醫護人員才發現未備血。2.病房護理人員將藥物給予當日接受手術且禁食病人，醫師查房時及時發現並阻止。3.手術前準備階段病歷少送，及時發現後請病房補送。4.手術前進行麻醉諮詢時發生病人資料黏貼錯誤，經及時發現後更正。5.手術前準備階段核對病歷時發現檢查報告貼錯。
請通報「手術事件」，事件發生階段請勾選『術前準備/術前準備程序不完善』。若事件及時被發現並且補齊資料，則屬『跡近錯失』。 舉凡應於術前完成之準備工作未執行(例如:禁食時間、同意書填寫、麻醉評估、備血、各類檢查、病歷資料調度或假牙飾品等移除)皆可歸於『術前準備程序不完善』。
手術事件
發現紗布未取出:1.病人因急迫性流產就醫，於急診手術室進行D&C，一星期後回門診追蹤，醫師發現上次D&C手術時的紗布在病人陰道內未取出；2.病人至醫院自然產，一個月後回門診追蹤，醫師發現病人陰道內有自然產時所使用的紗布未取出。以上兩種情況須通報至醫療照護事件或手術事件?
請通報「手術事件」之『術後處置/ 類型勾選異物滯留體內』。（自然產亦視為手術過程）
手術事件
病人入開刀房十，OR護理人員發現病人的手術前後記錄單部位寫錯，立即與病房主護反應並更正。在立即處理介入措施上，應勾選?
立即處理介入措施建議勾選：其他介入(醫療團隊進行溝通)
手術事件
入OR時發現病人假牙未取下，立即將假牙取下。其立即處理介入措施應勾選其他介入(移除與危害相關之設備或環境運作)嗎?
病人假牙非機構之環境設備，建議勾選：其他介入(醫療團隊進行溝通、說明移除病人假牙)，因OR仍應告知病房有此狀況發生。
手術事件
手術傷口感染是否有定義可參考?因一般大腸直腸外科手術後傷口感染(化膿)情形很常見，即使已使用預防性抗生素，也不是每種菌都有效，故術後感染發生較頻繁；類似案件是否須通報或是有何標準可界定手術傷口感染的異常?
術後傷口感染原因眾多，若是在術中受到汙染(如：非無菌物品與無菌物品接觸、非無菌的水滴或飛沫掉落於無菌區..等)，須通報「手術事件」，事件發生階段及類型勾選『手術過程/手術傷口汙染』。
傷害事件
病人打群架或起口角，是否依人數通報案件?
病人打群架或是起口角，只要通報一件傷害事件即可。
傷害事件
病人企圖自殺，該如何判斷傷害?如:病人因症狀干擾有幻聽、幻視、對現實產生誤解，並有以頭撞牆的自殺行為，制止檢查有紅腫，無嚴重外傷，有醫療介入(觀察；約束)
精神科病人由於病情影響而企圖自殺後，應依事件實際傷害程度判定傷害嚴重度，若因此增加探視、評估或處置頻率，應為中度以上傷害。
傷害事件 / 跌倒事件
被病人故意推倒是否要通報為傷害事件?
若病人蓄意推倒他人，請歸類於「傷害事件」中的身體攻擊。若非蓄意碰撞而導致的跌倒，則歸類於「跌倒事件」。 精神科病人之故意跌倒不須通報跌倒事件。
傷害事件 / 治安事件
病人或家屬，跟醫護人員發生口腳或肢體衝突，要通報至哪一類事件?影響對象是否只勾選員工，不勾選病人及其傷害程度?
1. 若事件由「病人」引起，跟工作人員、家屬訪客或其他病人間的口角或是肢體衝突，應通報「傷害事件」。 2. 凡事件「非病人」所引起，如若為家屬-家屬、家屬-工作人員、家屬-訪客間發生口角或是肢體衝突，或其他人員攻擊病人，則應通報「治安事件」。 3.病人攻擊工作人員，影響對象應含員工及病人，如病人未在事件中受傷，對健康影響程度可為無傷害。
傷害事件
1.病人出現身體攻擊造成傷害後，醫師開立精神科用藥(如:haldol)。2.病人出現身體攻擊導致疼痛，醫師開立止痛劑(如:acetaminophen)。以上事件發生嚴重程度是否為使用1-2劑藥物治療的中度傷害?
中度傷害所指的1~2劑藥物治療，係指此事件發生後對病人健康造成影響所使用的治療藥物。因此： 1. 由於病人出現身體攻擊行為，醫師因此而開立精神科藥物。其目的是「為了治療或控制病人原先疾病的症狀」，不屬於使用1~2劑藥物治療的中度傷害。 2. 病人因為身體攻擊行為造成傷害導致疼痛，醫師因此而開立止痛劑。其目的是「為了治療此傷害對病人健康造成的影響」，應認列為使用1~2劑藥物治療的中度傷害。
傷害事件
精神科病人因疾病因素，而有自傷、破壞設備、言語或肢體暴力情形，如病人因幻聽而拿物品敲牆壁、做出自傷動作或攻擊工作人員，此類事件是否須通報?
請通報「傷害事件」。 精神科病人因疾病病程而有的幻聽、自言自語等情形，無須通報。但若因此而有自傷或自殺行為，或與他人有言語衝突、身體攻擊、破壞設備等情形，則需通報。
傷害事件
精神科病人症狀導致的一些行為，如破壞物品，但對自己或他人的暴力行為，是否為TPR案件?
精神科病人因病情症狀影響而導致有破壞物品情形,仍應通報『傷害行為事件』, 傷害類型可選填『破壞設備』,事件發生可能原因則可探究是『與病人生理及行為因素相關—例如受病情影響,病人拒絕服藥或治療』或『與人員個人因素相關—例如未給予適當約束,未遵循醫囑給予治療』或『與溝通相關因素—例如病人與醫護人員溝通不良』,這些選項都可複選。
傷害事件
病人因生氣口頭表示要死，但無任何動作行為，是否需進行病安通報?如須通報，傷害程度為何?
"病人生氣表示要死"建議進一步評估此是否為病人當下生氣脫口而出的言語或是病人確實有自傷或自殺(含企圖自殺意圖，經評估確定有結束生命)行為，如確認病人有自傷/自殺意念，醫護同仁需進一步採取防護措施，則建議通報，由於即時的介入，使可能發生的事件並未真正發生於病人身上，因此傷害程度應為跡近錯失。
管路事件
病人自拔CVP-LINE:1.睡夢中自拔無出血，醫師評估須重插，是否算無介入?病人無傷害嗎?2.未重新插管，只使用加壓止血，傷害程度算中度嗎?
"1.若醫師判定依病情需要而重新置入管路即屬於醫療介入，不能勾選無介入。 2.請依照滑脫後的處置勾選此次事件對病人所造成的傷害程度：如果CVP-LINE自拔或滑脫後無出血則屬於無傷害、不需增加額外照護請勾選輕度、若須加壓止血，應勾選中度傷害。
管路事件
病人自拔Endo，生命徵象未改變，傷害程度算中度嗎?未重新插管也算中度嗎?
"自拔Endo後若需重新插管視為額外之處置，故應算中度傷害。即使不需重新置入，拔管對於呼吸道仍有一定程度的損傷及提高缺氧的風險，此外，仍需額外探視、評估、觀察或處置，所以還是屬於中度傷害；若病人自拔後，導致需緊急氣切或是延長住院則應勾選重度。
